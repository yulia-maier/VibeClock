# VibeClock

Маленький радужный таймер для Windows 10/11 x64. C#, WPF, .NET 10. Окно 220×220 логических пикселей, без рамки и заголовка; размер учитывает масштаб экрана Windows.

## Запуск

**`dist/portable/VibeClock.exe`** — готовая автономная версия. Просто запустите; устанавливать .NET и получать права администратора не нужно. Первый запуск может занять чуть больше времени: .NET распаковывает встроенные нативные библиотеки в свой пользовательский кэш.

**`dist/framework-dependent/VibeClock.exe`** — компактная версия для компьютеров с установленным **.NET 10 Desktop Runtime x64**. Обычного .NET Runtime без WPF недостаточно.

## Управление

| Действие | Результат |
|---|---|
| Потянуть ручку или нажать и провести по циферблату | Выбрать 1–60 минут; отпускание мыши запускает отсчёт |
| Нажать верхнее деление `0` | Выбрать полный час |
| Кликнуть центральную ручку | Пауза / продолжение |
| Правый клик по ручке | Сброс до нуля без звука |
| Потянуть лавандовый край | Переместить окно |
| Правый клик вне ручки | Открыть четыре настройки |

В контекстном меню: **Always on Top**, **Start with Windows**, **Sound On/Off**, **Exit**. Галочка у Sound On/Off означает, что звук включён. По умолчанию звук включён, автозапуск и закрепление поверх окон выключены.

Также работают стрелки для выбора минут и Enter для запуска, пробел для паузы, Escape для сброса и Shift+F10 для контекстного меню. Дополнительных кнопок на циферблате нет.

Радуга привязана к делениям, а ручка показывает оставшееся время. При завершении один раз звучит мягкий синтезированный колокольчик. После закрытия отсчёт не сохраняется: при следующем запуске таймер стоит на нуле.

## Настройки и автозапуск

Положение окна, звук и Always on Top сохраняются в `%LOCALAPPDATA%\VibeClock\settings.json`. Если монитор отключён, окно возвращается в рабочую область ближайшего доступного экрана. Повреждённый файл настроек заменяется стандартными настройками при следующем сохранении.

Автозапуск использует только `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `VibeClock`, с путём к текущему exe в кавычках. Он включается только по выбору пользователя. Перед включением положите exe в постоянную папку. После перемещения включите автозапуск заново из нового расположения. Для удаления сначала отключите Start with Windows и закройте приложение, затем удалите exe и при желании папку настроек.

## Сборка

Нужны Windows и [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0). Скрипты сначала используют локальный `.tools/dotnet/dotnet.exe`, если он есть, иначе `dotnet` из PATH.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\test.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1 -FrameworkDependent
```

Или откройте `VibeClock.slnx` в IDE с поддержкой .NET 10. Приложение не использует сторонних библиотек. Автономная публикация включает .NET Desktop Runtime, поэтому её файл значительно больше компактной версии; это не размер кода таймера.

## Структура

| Папка | Назначение |
|---|---|
| `src/VibeClock/Timer` | Отсчёт по `TimeProvider.GetUtcNow()`, deadline, пауза, одно событие завершения |
| `src/VibeClock/Rendering` | Пиксельный корпус и цифры, статическая радужная текстура, изменяемая маска сектора |
| `src/VibeClock/Interaction` | Углы мыши, шаг в одну минуту, корректный переход через верх шкалы |
| `src/VibeClock/Widget` | Окно, события мыши и клавиатуры, контекстное меню, положение на мониторах |
| `src/VibeClock/Settings` | JSON-настройки с атомарной заменой файла |
| `src/VibeClock/Startup` | Автозапуск для текущего пользователя |
| `src/VibeClock/Audio` | Короткий PCM-колокольчик, созданный в памяти |
| `tests/VibeClock.Tests` | Проверки логики и настоящей WPF-отрисовки без внешнего тестового фреймворка |

Визуальная концепция воссоздана по предоставленным референсам средствами C#: исходные PNG не нужны при запуске. Для изменения рисунка редактируйте `PixelArt.cs`; палитра радуги находится в `RainbowProgress.cs`. Статичные слои кэшируются, сектор обновляется 30 раз в секунду только во время отсчёта. В паузе и при нуле цикл перерисовки остановлен.

Тесты проверяют задержки UI и сон, точную паузу, завершение ровно один раз, сброс, границы длительности, направление шкалы, переход 60/0, настройки и неизменность цветов при уменьшении сектора. Они создают PNG состояний 0/15/30/60 минут в `artifacts/previews` для визуальной проверки.
